# АвтоКлюч — калькулятор стоимости авто с Copart / IAAI

Два связанных продукта в одном репозитории:

| Что | Где | Язык | Тема |
| --- | --- | --- | --- |
| **Публичный сайт** — лендинг + витрина авто | `/` | украинский | светлая, тёплая |
| **Внутреннее приложение** — калькулятор для менеджеров | `/app` | русский | тёмный графит |
| **API** — расчёты, тарифы, роли, витрина | `/api` | — | — |

Оба фронтенда живут на одном хосте: сессия в httpOnly-cookie работает без CORS.

---

## Быстрый старт

```bash
cp .env.example .env        # если .env ещё нет
docker compose up --build
```

Стенд поднимется на **http://localhost:8081**. Dev-nginx отвечает на любой адрес,
которым до него достучались, поэтому также работают `westauto.localhost:8081`,
`local.westauto.com.ua:8081` и IP машины.

Первый вход: логин `admin`, пароль `admin12345` (меняются в `.env`, раздел
`BOOTSTRAP_ADMIN_*`). **Смените пароль после первого входа** — в приложении
кнопка «Сменить пароль» в разделе «Настройки».

### Красивый адрес http://local.westauto.com.ua

На этой машине 80-й порт занят системным nginx, поэтому стенд слушает 8081.
Чтобы проект открывался без порта, добавьте проксирующий вход:

```bash
sudo cp infra/nginx/host-vhost.conf /etc/nginx/sites-enabled/local.westauto.com.ua.conf
sudo nginx -t && sudo systemctl reload nginx
echo '127.0.0.1 local.westauto.com.ua' | sudo tee -a /etc/hosts
```

Если браузер на Windows (WSL), нужна ещё строка в
`C:\Windows\System32\drivers\etc\hosts` (Блокнот от имени администратора):

```
127.0.0.1 local.westauto.com.ua
```

Свободен 80-й порт — поставьте `HTTP_PORT=80` в `.env`, и всё это не нужно.

## Что уже работает

- **Мгновенный пересчёт.** Кнопки «Пересчитать» нет: движок расчёта —
  чистая функция в `packages/shared`, она же считает в браузере и на сервере.
- **Коммерческое предложение в PDF** — полноразмерный документ A4 с
  характеристиками, разбивкой, курсом и контактами. Язык документов для
  клиента (UA/RU) переключается отдельно от языка интерфейса.
- **Ссылка на расчёт для клиента** — вместо учётных записей клиентам.
  Отзывается одной кнопкой, видно число просмотров.
- **Наблюдение за лотами** — ставки проверяются раз в 15 минут, история
  ставок, уведомления при превышении потолка.
- **Импорт и выгрузка тарифов** — CSV и вставка прямо из Excel / Google
  Sheets, с построчным предпросмотром до загрузки.
- **Устанавливаемое приложение (PWA)** — ставится на рабочий стол,
  открывается отдельным окном.
- **SSR публичного сайта** — страницы витрины приезжают поисковику готовой
  разметкой; `sitemap.xml` и `robots.txt` собираются из базы.
- **HTTPS** — самоподписанный для стенда, Let's Encrypt для боя.
- 6 площадок: Copart, IAAI, Copart UK/Canada, IAAI Canada, Manheim.
- **Растаможка через baza-gai.com.ua** с тремя уровнями надёжности:
  живой ответ → последний успешный из кеша с пометкой «не обновлено» →
  локальная оценка с явным предупреждением.
- **Тарифы и настройки в БД**, правятся в интерфейсе, каждая правка
  попадает в журнал: кто, когда, `$1 640 → $1 720`.
- **Роли**: администратор правит тарифы, настройки и пользователей;
  менеджер считает и видит свою персональную скидку к доставке.
- **История расчётов** с поиском, фильтрами и кнопкой «скопировать в новый»
  (пересчитывает по сегодняшним тарифам).
- **Карточка для клиента** — всегда светлая, с кнопками «Копировать» и
  «Сохранить PNG». Маржа и себестоимость в неё не попадают никогда.
- **Витрина на сайте** — публикуется прямо из готового расчёта.
- **Подтяжка лота** с Copart/IAAI с мягким переходом на ручной ввод.
- **Курс НБУ** подтягивается автоматически и фиксируется в снимке расчёта.

## API-ключ baza-gai.com.ua

Пока ключа нет, растаможка считается **локальной оценочной формулой** —
в интерфейсе это видно жёлтой плашкой и пометкой у строки.

Бесплатный ключ (1000 запросов/мес): форма «Получить API ключ» на
[baza-gai.com.ua](https://baza-gai.com.ua/) — нужны название проекта, e-mail
и ожидаемый объём запросов. Ключ придёт письмом.

Дальше:

```bash
# в .env
BAZA_GAI_API_KEY=ваш_ключ
```

```bash
docker compose restart api
```

Ключ читается только на сервере и во фронтенд-бандл не попадает.

> Локальная формула в `packages/shared/src/customs-estimate.ts` — это
> **запасной вариант, а не источник правды**. Ставки, пороги акциза и
> пенсионного сбора меняются законодательством; в конфиге они вынесены
> наверх, но проверять их вручную придётся вам. Именно поэтому ТЗ и просит
> считать растаможку внешним API.

### HTTPS на стенде

```bash
./infra/tls/make-local-cert.sh
docker compose -f docker-compose.yml -f docker-compose.tls.yml up -d
```

Откроется на `https://local.westauto.com.ua:8443`. Нужен, чтобы проверить
установку приложения и secure-куки: браузеры разрешают то и другое только
по https (исключение — `localhost`).

### Боевая сборка

```bash
docker compose -f docker-compose.prod.yml up -d --build
```

Три сервиса: `api`, `site` (отрисовка страниц) и `web` (nginx перед ними).

Перед выкаткой на GCP обязательно заменить в `.env`:

```bash
openssl rand -hex 48        # → JWT_SECRET
```

- `JWT_SECRET` — иначе чужие сессии подделываются тривиально
- `POSTGRES_PASSWORD`
- `BOOTSTRAP_ADMIN_PASSWORD`

**HTTPS в бою обязателен.** При `NODE_ENV=production` кука сессии помечается
`Secure`, и браузер отдаёт её только по https. Без TLS вход будет выглядеть
как «залогинился и тут же разлогинился». Настройка — в
`infra/nginx/prod-tls.conf`, там же команды certbot.

## Что осталось за рамками

- **HTTPS** — стенд локальный, сертификаты не настраивались.
- **Подтяжка лотов** написана и работает как модуль, но Copart и IAAI
  активно закрываются от автоматизации: рассчитывайте на ручной ввод,
  автоподтяжка — приятный бонус, который может отвалиться в любой момент.
  Отключается через `LOT_FETCHER_ENABLED=false`, заменяется на партнёрский
  API добавлением одного адаптера в `apps/api/src/services/lot-fetcher/`.
- **Реальные контакты и цифры** на сайте — плейсхолдеры в квадратных
  скобках, правятся в `apps/site/src/config.ts`.
