# Состояние проекта

Дата среза: 17.09.2026

## Как запустить

```bash
cp .env.example .env     # если .env ещё нет
docker compose up -d --build
```

Открывается на **http://localhost:8081** (а также `westauto.localhost:8081`,
`local.westauto.com.ua:8081` и по IP машины — dev-nginx отвечает на любой адрес).
`/app` без косой черты редиректится на `/app/`.

Вход: `admin` / `admin12345` → **смените пароль** в разделе «Настройки».
Приложение: `/app`. Документация внутри приложения: `/app/docs`.

## Что сделано

### Внутреннее приложение (`/app`, русский, тёмная тема)
- Калькулятор с мгновенным пересчётом, движок — общая чистая функция
  (`packages/shared/src/calc.ts`), она же считает на сервере при сохранении
- Все поля ТЗ: ставка, доставка, аукционный сбор, комплекс, растаможка,
  сертификация, комиссия, Swift, страховка фрахта, портовые расходы,
  экологический сбор, маржа
- Ручная правка любой строки, выключение ненужных строк, «было → стало»
- Курс НБУ с фиксацией вручную на конкретный расчёт, итог в ₴ и €
- Карточка для клиента: копирование, PNG, **КП в PDF** (A4), переключатель
  языка документов UA/RU
- Тарифы с историей правок, **импорт/экспорт CSV** (и вставка из Excel/Sheets)
- Настройки, пользователи, роли, персональные скидки
- История расчётов, поиск, фильтры, «скопировать в новый»
- **Ссылка на расчёт для клиента** — закрывает пункт ТЗ про роль «клиент»
- **Наблюдение за лотами** с историей ставок и уведомлениями в приложении
- Витрина: публикация расчёта на сайт, фото, статусы
- Документация для менеджера и админа (`/app/docs`)
- **PWA**: устанавливается на рабочий стол, кнопка в боковом меню
- Горячие клавиши, автосохранение черновика, тёмная/светлая тема

### Публичный сайт (`/`, украинский, светлая тема)
- Лендинг: хиро, 5 шагов, тизер калькулятора, услуги, гарантии, футер
- Витрина авто: список, фильтры по статусу, карточка авто
- Страница расчёта по ссылке от менеджера (`/rozrahunok/:token`)
- Форма заявки → падает в «Настройки» приложения
- Вход в приложение: ссылка в шапке, в тизере и в футере
- **SSR**: страницы собираются на сервере, поисковик видит готовую разметку
- `sitemap.xml` и `robots.txt` из БД

### Инфраструктура
- Docker: `docker-compose.yml` (разработка), `docker-compose.prod.yml` (бой),
  `docker-compose.tls.yml` (HTTPS на стенде)
- **HTTPS**: самоподписанный для стенда (`infra/tls/make-local-cert.sh`),
  боевой конфиг с Let's Encrypt (`infra/nginx/prod-tls.conf`)
- 4 миграции, forward-only, с контрольными суммами
- 6 площадок: Copart, IAAI, Copart UK/Canada, IAAI Canada, Manheim

## Что осталось

| Что | Почему отложено |
|---|---|
| API-ключ baza-gai.com.ua | Форму на baza-gai.com.ua отправляет владелец бизнеса — нужен e-mail компании. Пока ключа нет, растаможка считается локальной оценочной формулой с предупреждением. Ключ ставится в `.env` → `BAZA_GAI_API_KEY`, перезапуск api |
| Реальные контакты и цифры сайта | Плейсхолдеры в квадратных скобках: `apps/site/src/config.ts` |
| Пороги пенсионного сбора | В `packages/shared/src/customs-estimate.ts` — привязаны к прожиточному минимуму, меняются ежегодно, **нужно сверить** |
| Уведомления письмами | Почтового сервера нет, уведомления живут в приложении (колокольчик) |

## Перенос на сервер

Архив собирается командой:

```bash
./make-release.sh
```

На сервере (Debian, Docker установлен):

```bash
tar xzf avtoklyuch-*.tar.gz && cd avtoklyuch
cp .env.example .env
openssl rand -hex 48          # → JWT_SECRET в .env
nano .env                     # JWT_SECRET, POSTGRES_PASSWORD, пароль админа
docker compose -f docker-compose.prod.yml up -d --build
```

Затем HTTPS: `certbot certonly --standalone -d westauto.com.ua`,
подключить `infra/nginx/prod-tls.conf` (инструкция внутри файла).
