**Что за проект.** Один сервер, на нём два публичных сайта и одна общая CRM
для компании WestAuto — она возит авто с американских аукционов Copart и IAAI
в Украину под ключ.

```
apps/api/            одна CRM на все сайты (Fastify + PostgreSQL)
apps/app/            внутреннее приложение, /app на любом домене
apps/site-autokey/   сайт АвтоКлюч
apps/site-westauto/  сайт WestAuto + сайты агентов на его поддоменах
packages/shared/     движок расчёта — одна чистая функция на фронт и бэк
```

**Репозиторий:** `git@github.com:sivtsov-pavel/westauto.git`

## Важное, на чём мы уже спотыкались

- **Порт.** На этой машине 80-й скорее всего свободен — поставь `HTTP_PORT=80`
  в `.env`, тогда адреса откроются без `:8081`. Если занят — оставь 8081 и
  говори мне адреса с портом.
- **Два сайта различаются по имени домена.** Без записей в `/etc/hosts`
  откроется только АвтоКлюч (он default), WestAuto — нет. Это не поломка.
- **Никогда не запускай `git rebase --root`** и другие переписывающие историю
  команды на этом репозитории. Один раз это стёрло рабочий каталог целиком.
  Если нужно поправить историю — сначала скажи мне.
- **База заведётся с нуля:** админ, 16 тарифов, 10 машин в витрине. Данные с
  другой машины не переезжают — они не в git. Как перенести дампом, написано
  в `TRANSFER.md`.
- **Пароль администратора** по умолчанию `admin12345` — напомни мне сменить его
  в приложении: Настройки → Сменить пароль.

## Как мы работаем дальше

Правки делаем в одном месте за раз, потом:

```
git add -A && git commit -m "что сделали" && git push
```

На другой машине и на сервере: `git pull && ./start.sh`
